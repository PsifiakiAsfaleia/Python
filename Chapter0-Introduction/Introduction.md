# Chapter 0:-

## What is Programming?
Computer programming is the process of creating a detailed set of instructions that tells a computer how to perform a specific task or solve a problem.

## What is Python?
- Python is a high-level, general-purpose programming language designed to be easy to read and write.
- Created by **Guido van Rossum** and released in **1991**.
- Python is widely used in Artificial Intelligence, Data Analysis, Web Development, Automation and Software Testing.

## #Key Feature:-
- **Beginner-Friendly:** Uses Clear, readable syntax and clear indentation instead of complex symbols or curly braces.
- **Interpreted:** Code executes line-by-line immediately making testing and debugging incredibly fast.
- **Dynamically Typed:** You do not need to declare variable types; the system determines them automatically at runtime.
- **Cross-Platform:** Runs seamlessly across Windows, MacOS, Linux, and Microcontrollers.
- **Massive Ecosystem:** Offers a vast “Batteries-included” standard library and thousands of third-party packages.

## Pip:-
Pip is the standard **package manager** for Python. You can use pip to install external modules on your  system.
```bash
Pip install “package”
```

## Modules:-
In Python, a module is simply a **file containing python code** ( with a .py extension). There are two types of modules in Python.
1. **Built in Modules:** Built in Modules are preinstalled with python.
2. **External modules:** External Modules need to be installed using pip or conda.
